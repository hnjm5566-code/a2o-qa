# A2O 知識問答助手

一個單頁的 AI 聊天機器人，針對 **A2O（鹿溪衛浴，虛構）** 的新人須知進行知識問答。可用於公司內部新人訓練、客服與業務部門快速查詢規範。

## ✨ 功能
- 💬 質感聊天介面（深色、氣泡式）
- 🧠 僅依據內建 A2O 知識庫回答，不憑空捏造
- 🔒 使用者需輸入 **Groq API Key** 才能使用（key 只留在瀏覽器，不會上傳）
- 📚 涵蓋：新人須知（2026版）、退換貨辦法、報價流程
- 🚫 自動排除已停用的「2024版」規定

## 🚀 使用方式
1. 開啟 `a2o-qa.html`（或 GitHub Pages 線上版）
2. 在上方輸入你的 **Groq API Key**（`gsk_...`）並按「連接」
3. 開始提問，例如：
   - 「業務可以給客戶幾折？」
   - 「退貨期限是多久？」
   - 「客訴要怎麼回覆？」

## 🔑 取得 Groq API Key
1. 前往 https://console.groq.com 註冊/登入
2. 建立 API Key（格式：`gsk_...`）
3. 貼回網頁即可

> 注意：產生回答會消耗 Groq 額度。API Key 僅存在於你的瀏覽器分頁中。

## 🧩 技術細節
- 純前端 HTML（無後端）
- 直接呼叫 Groq `chat/completions` API
- 模型：`llama-3.1-8b-instant`
- 知識庫內嵌於 `<script>` 中的 JS 物件
